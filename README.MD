# DSA Practice

This repository contains my solutions and notes while practicing **Data Structures and Algorithms (DSA)**.  
The goal is to improve problem-solving skills, coding efficiency, and prepare for technical interviews.

## 🚀 Topics Covered
- Arrays
- Strings
- Linked Lists
- Stacks & Queues
- Trees & Graphs
- Sorting & Searching
- Dynamic Programming
- Recursion & Backtracking
- Other common patterns

## 🛠️ Languages Used
- **Python / JavaScript** (main)

## 🎯 Goals
- Strengthen problem-solving skills
- Learn different approaches to solve problems
- Build confidence for coding interviews

## 📁 Structure
- `leetcode/`: LeetCode solutions (`LC_*.py`) with simple print tests.
- `contests/`: Misc/contest-style problems (standalone scripts).
- `at_coder/`: AtCoder practice (e.g., DP problems).
- `main.py`: Scratchpad/experiments.

## ▶️ Running
- Run any script directly with Python, e.g. `python leetcode/LC_3021.py`.
